# Jonathan Arnaldo

Frontend software engineer. I build high-leverage interfaces for complex products — 10+ years working on high-scale, AI-native interfaces, LLM streaming architecture, real-time data systems, and React / TypeScript at scale.

## How I build

- **Performance** — fast initial renders, responsive data-heavy interactions, efficient streaming, deliberate client-side work.
- **Architecture** — clear component boundaries, reusable primitives, abstractions that solve real product problems.
- **AI-native UX** — interfaces for streaming, uncertainty, tool calls, human-in-the-loop workflows, and evolving model behavior.
- **Product thinking** — working directly with product, design, and customers to understand the problem before the implementation.
